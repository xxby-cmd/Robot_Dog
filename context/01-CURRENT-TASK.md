## 新机入口

- `baseline/desktop_install/bootstrap.py preflight`：只读前置条件检查。
- `首次部署机器狗.cmd` 或 `bootstrap.py install --start --wait`：下载校验、生成本机密钥、建盘、首次安装。
- `运行本机部署机器狗.cmd`：本机配置的图形启动器。
- `baseline/desktop_install/vm.py`：本机 SSH/QMP、上传下载、GPU 检查与运动自测。
- 默认本机配置 `.robotdog-desktop.local.json`，运行目录在仓库旁；二者不要求原笔记本盘符。
- 不必索取旧 `E:\RobotDogRuntime` 的下载地址，也不必传递旧私钥；安装使用 Git 源码与公开基础文件。
- 发布交接时保留了笔记本原工作区，没有切换其分支或清理现场；新机以远端 `main` 或交接分支的新克隆为准，不在旧脏工作区盲目 pull/reset。
