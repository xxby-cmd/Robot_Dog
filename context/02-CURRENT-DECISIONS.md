# 已确认决策与事实边界

## 稳定约定

- 先 Baseline，再原理，再共同讨论创新；用户负责原理研究和最终解释，Codex 负责工程实现与配合讲解。
- 近期纯仿真、Go2、Gazebo＋一种 SLAM；真实 Go2、Unity、双 SLAM 不在本阶段范围。
- 用户已比较并选择独立 Jazzy＋Harmonic＋CHAMP。换主控制、ROS、仿真平台或主要 SLAM 路线仍须询问。
- 下一次汇报为 2026-11-04，按已经实际验证的进度展示。
- 一次一项任务，工程自测通过后交用户验收；验收前不推进下一功能。
- 不影响 eNSP/VirtualBox；Windows 虚拟化或安全设置变更须先说明依据和影响，等待用户选择。

## 当前迁移方式

- 公开仓库保存源码、工具、规则、规划、压缩上下文和历史证据。
- 新电脑从固定公开 URL 取得 QEMU / Ubuntu / 解压工具 / ISO 库，校验后在专用运行目录使用。
- 7-Zip MSI 仅作数据读取和便携提取，不执行 MSI 安装动作；ISO 库本地导入，不全局 pip 安装。
- SSH 私钥在目标电脑本地生成；不要求从笔记本复制密钥，不提交生成后的本机配置或运行磁盘。
- Windows OpenSSH 客户端和 WHPX 只检查；缺少组件时按部署说明处理，不自动改虚拟化设置。
- 已安装私人 VM 的内部历史无需公开：新机以相同代码和安装配方恢复功能，再做新机验证。

## 已知限制

- VirGL 使用宿主 GPU，不是 GPU 直通，也没有给虚拟机独占分配显存。
- 软件包下载依赖网络和当前 apt 仓库；精确基础镜像/源码已锁定，apt 实际版本需记录。
- 性能会受硬件、渲染器、负载、窗口状态影响，台式机必须独立测量。
- 当前没有 SLAM 定位、导航修正或自动翻身；低速遥控行走结果不能等价为完整系统通过。
- 正常退出仍有偶尔较慢的历史记录，拷盘前必须确认进程退出、磁盘释放。

## 暂未决定

具体 SLAM 算法、目标检测类别/场景、后续导航与探索验收细节，按对应任务调查后共同决定。
不把未来研究建议写成老师已经确认的要求，不把下载源码写成已经验收的成果。
