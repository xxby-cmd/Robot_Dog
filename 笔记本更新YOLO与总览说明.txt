笔记本更新 YOLOv10 与演示总览（2026-10-30）

已有机器狗运行环境
1. 在笔记本原Robot_Dog工程目录执行：
   git pull --ff-only origin main
   main与codex/desktop-handoff-20261027会同步本批功能。若提示本地修改或分支分叉，保留改动后再处理，不用reset/clean覆盖。
2. 关闭旧的Windows机器狗启动器，重新打开“运行本机部署机器狗.cmd”。点击“应用工程更新”；它会启动本机原虚拟机，等待Ubuntu就绪、保留旧源码并同步新工具、补齐依赖和编译。“启动行走环境”也走相同更新检查。
3. 不要重新执行首次安装或retry-install，不要复制台式机.robotdog-desktop.local.json或robotdog-host.json。现有实例会继续使用笔记本自己的运行目录、端口、显示与显卡设置，个人速度、地图和本机密钥保留。多个运行环境不能唯一确定时按提示显式选择，程序不覆盖其他实例。
4. 总览自动加载传感器行走仿真。等关节12/12、机器狗站稳，右上“开始建图”，右下“开始检测”。“添加示例椅子”加入真实三维测试目标；“参数”展开置信度与处理频率，修改后停止并重开检测。
5. 首次“开始检测”自动准备独立ONNX Runtime CPU环境并下载约9.4MB的固定模型，TLS和SHA256都要通过；示例椅子首次也需要联网。无需新账号、训练或付费API。网络慢时按YOLO使用说明准备同版本已校验离线wheel/模型缓存，不关闭TLS或跳过哈希。
6. 可在Windows运行“运行目标检测测试.cmd”，报告写入笔记本自己的运行目录 verification/vision/本次编号；先添加椅子并开始检测，默认检查chair。台式机的结果不冒充笔记本结果。

尚未安装环境的新电脑
在源码目录运行“首次部署机器狗.cmd”，沿已有Windows x64/Python/Tk/OpenSSH/WHPX预检及安装流程建立独立Ubuntu环境。详见“新机部署说明.txt”；部署器不自动更改Windows虚拟化/安全设置。不要为本次更新重装已经可用的笔记本环境。

界面与退出
总览左侧三维、右上地图、右下检测、下方控制和关键读数；可拖分隔条、点全屏、把三维独立后放回，详细传感器按需打开。独立行走控制仍可通过来宾 ~/bin/start-panel.sh --classic 打开，不与总览同时开同一控制面板。
关闭总览会停止它启动的行走/建图/检测，保存的地图及个人配置保留；安全关闭虚拟机仍用Windows启动器的按钮，不强制关掉运行盘。

实测边界
台式机40项主机检查、默认及1100×650布局、实际按钮回调、地图保存、检测重开、原生窗口晚到恢复及并行物理行走通过。没有在笔记本实机复测；使用共同安装配方和本机配置不等于已证明笔记本帧率、所有COCO类别准确率或长期稳定性。原有虚拟机SEGV/init panic、慢速和一次无移动命令前翻倒的现场已记录，原因尚未根治。
