2026-10-27 头部碰撞、速度调参与双机适配更新

适用：已经安装 Jazzy / Harmonic / CHAMP 的笔记本或台式机。
main 与 codex/desktop-handoff-20261027 本轮同步更新；不需要迁移台式机本机配置、私钥或运行盘。

1. 关闭旧的 Windows 启动器窗口。在原仓库当前分支执行 git pull --ff-only。
   如果提示本地修改冲突或分支分叉，保留现场，不使用 reset --hard、clean 或强制覆盖。
   也可另行克隆新目录，保留旧工作区。新克隆会识别原已安装运行目录，不重复建盘。
2. 双击仓库“运行Go2行走仿真.cmd”或“运行本机部署机器狗.cmd”。
   程序会启动或识别同一虚拟机，按源码变化停止本工程仿真、备份来宾源码、同步并编译，然后重开新版面板。
   更新时等待启动器完成，不使用“首次部署”或 retry-install 重装已完成的系统。
3. 等面板显示关节 12/12、控制器激活并站稳，再低速操作。
   点击“速度调参”，分别修改前进/后退 m/s、转向 rad/s，点击“保存并应用”。
   更新后的按钮与键盘共用设置；保存时先停止；松开、失焦、连续按住上限与断令停止保护保留。

本机适配：自动检查各固定本地磁盘根下 RobotDogRuntime / RobotDogDesktopRuntime，恢复唯一完整实例。
笔记本原 E:/RobotDogRuntime 可继续使用；CPU、内存、显示和端口只保存在本机配置，不需要修改源码盘符。
多套完整环境时要求明确选择；自定义路径可先在当前终端设置 ROBOTDOG_RUNTIME 再从同一终端启动入口。
不要把台式机 .robotdog-desktop.local.json 或 robotdog-host.json 复制给笔记本；不同硬件分别生成配置。
台式机 i7-14700K / Windows 26300 使用已验证的本实例 IRQ 选项，笔记本保持默认 WHPX；独显按实际 NVIDIA 加速核对，不限定 4060 型号。
